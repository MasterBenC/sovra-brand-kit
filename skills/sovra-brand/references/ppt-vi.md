# PPT 执行参数

画布锁定 10 × 5.625 英寸，原点在左上。不要改成 13⅓ × 7½ 英寸。坐标的机器依据是 `assets/role-styles.json`，由 `scripts/build.py` 写入，不要在成品里手调。

## 颜色

| 角色 | 色值 | 用途 |
|---|---|---|
| 午夜黑 | #080912 | 封面底，使用 `assets/cover.png`，不重画 |
| 白 | #FFFFFF | 目录、章首、正文 |
| 正文 | #18181C | 主标题和正文 |
| 结构 | #5145FF | 步骤、表头线、重点 |
| 强调 | #FF925C | 少量强调、章号。白底小字不用浅橙承担关键内容 |
| 辅助灰 | #85858F | 页码、来源、页脚品牌 |

不新增科技蓝、青色、粉色、弧光或刀锋。

## 固定文字

| 角色 | 规则 |
|---|---|
| 正文主标题 | x0.42 y0.37 w9.16；单行高 0.42，双行高 0.78；21pt；行距 26pt；左对齐；边距 0；不自动缩小 |
| 页码 | x9.225 y5.325 w0.3375 h0.15；Arial 7.5pt；#85858F；右对齐。封面没有页码。第二页是 02 |
| 来源 | x0.42 y5.12 w9.16 h0.16；8pt；#85858F |
| 页脚品牌 | 小号灰色「灵能涌现」。不写英文全称，不放右下英文品牌 |
| 章首短名 | 右上 8pt 灰色，取 `short_title` |

正文主体在单行标题后从 y1.05 开始，双行标题后从 y1.34 开始，到 y5.00 结束。来源区之上必须留空。

## 封面信息顺序

品牌 → 活动身份 → 主题 → 学员价值 → 主讲人与真实身份。署名格式是「主讲人：姓名」。封面文案不加句号。身份用这份材料里的真实信息，不抄上一门课的讲师。

## 输入

根字段：`title`、`short_title`、`event`、`subtitle`、`goal`、`speaker`、`credentials`、`sections`。`credentials` 一至三条。可选 `opening_notes`。

每章：`title`、`summary`、`pages`。可选 `notes`。

每页：`type`、`title`、`notes`。可选 `lead`、`takeaway`、`source`。

- flow / cards：`items` 为 2–4 组「短标题、说明」
- table / case / data：`columns` 2–4 列，`rows` 1–5 行，每行列数相同
- case / data 必须有 `source`
- visual 的 `asset` 相对 JSON 文件，必须是 PNG，并有 `provenance`

换行用 JSON 字符串里的 `\n`，在语义处断开。超宽或超高时脚本失败，这时拆页或改写，不改字号。

## 明确不用

A4 的页眉 t.e.c、A4 的「正文从 1 计数」、旧版 36pt 标题、深色章节页、正文左上品牌眉题，都不进入 PPT。
